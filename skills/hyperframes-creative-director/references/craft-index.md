# Craft vocabulary and source status

This is a discovery index, not an enum, priority gate or approved-technique list. **All new source studies are authored but unexecuted and visually unverified.** “Study source” means a reproducible source path exists via the family reference; it does not mean the example is proven or ready for production. “Related study” is not an implementation of every alias. “Index only” means conceptual guidance with no shipped demonstration. HyperFrames remains the renderer.

Sources are issue proposals, not independently observed films. Issue links below refer to this repository. User additions reflect the approved scope. See [showreel status](showreel-index.md), [negative guidance](anti-patterns.md) and [selection](technique-selection.md).

## Unavailable showreel

Issue [#10](https://github.com/geekjourneyx/hyperframes-creative-director/issues/10) names S0–S12 (13 scenes), TR (12 transitions) and END, but does not provide their full names or accessible source/video. Each S0, S1, S2, S3, S4, S5, S6, S7, S8, S9, S10, S11 and S12 remains **unmapped / missing source**. Each TR0–TR11 is an inventory placeholder only; the original indexing convention itself is unverified. END is described as a silent falling-ball/punctuation lockup, not observed here. Reported ~2-second spacing and 26-second ending are issue claims, not recovered timecodes. Do not invent mappings or count these placeholders as implemented coverage.

The issue's named usable ideas (infinite zoom/device, compare/modules, glitch/inspect, silent punctuation) and specialized ideas (easing editor, point clouds, harmonic, isometric city) have destinations above. Obtain the actual source, license and export before recovering exact aliases and timecodes. The six native studies are independent examples, not replacements falsely labeled S0–S12.

The twelve detailed IDs are listed in [craft-library.md](craft-library.md). Scene names describe implementation shapes, not ideas or required story beats. Closed style-package selection, mandatory dark defaults, technique/camera/transition quotas and a prerequisite catalog-registration step are intentionally not adopted.
